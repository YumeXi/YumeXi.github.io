# 背景

- 现代的文档排版软件多聚焦于 PDF 等形式，但是 PDF 非常不适应手机小屏等阅读介质，也不可能具有交互式的阅读体验。
- 虽然 HTML 带来了交互的可能性，但是它并不是为编写文档而存在的，存在诸多噪音与不便。
- Markdown 确实拥有人类易写易读的优势，但是
  1. 语法混乱
  1. 允许嵌入任意 HTML 元素
  1. 缺乏（即使是基础的）排版功能
  1. 依然不存在交互式体验
