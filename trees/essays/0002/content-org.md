# 背景

不同类型的文档往往有不同的组织需求，但是这些需求实际上都可以用图来表达，然后编写函数特化为某种形状？（就像 Lisp OS 的 unordered directory 一样）。基于这个出发，结合 [交互式文档](./interactive-document.md) 和 LLM，可以做的事情至少有：
  - research agents
  - notebooks
  - neo wikipedia

也许就像一碗汤一样，汤里在一起的溶质（所有文本）可能受一些更大的粒子（标题或什么）吸引结晶成图的节点。
